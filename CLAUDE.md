# Редактор rich-контента Ozon — инструкция для работы с кодом

Инструмент раздела «Менеджмент» сайта tea-master-team.ru (магазин «Чайный Мастер» на Ozon). Владелец — Марк, не программист: общение и комментарии в коде на русском, объяснять простыми словами.

## Стек и правила

- Node.js 22, **без сторонних библиотек** (как «Воронка продаж WB»). Не добавлять npm-зависимости без решения Марка.
- Интерфейс — обычные ES-модули в `public/`, без сборки.
- Вход — только по ссылке из «Менеджмента» (`#t=ТОКЕН`, 60 минут), своего пароля нет (решение Марка). Токен проверяется запросом `AUTH_SQL` к базе сайта через `psql`.
- `.env` и `data/` в git не попадают.
- Перед коммитом: `npm test`.

## Формат Ozon

- JSON rich-контента версии 0.3. Поля сверены с официальной схемой https://st.ozone.ru/s3/artifact/schema.json и живыми карточками (ноябрь 2026): `raShowcase` (`billboard`, `chess`, `tileL`, `roll`), `raTextBlock` (с кнопкой-ссылкой в конце текста), `list` (`bullet`, `image`, `number`), `raTable`, `raVideo` (только `embedded` — файл .mp4; YouTube убран, решение Марка 27.11.2026).
- Текст: только размер `size1`–`size7` (12–38 px), цвет `color1`–`color4` и выравнивание; шрифт, жирный и курсив Ozon не даёт. Стиль блока — поле `style: {title, text}`, значения по умолчанию — `DEFAULT_STYLE` в `public/rich.js`.
- Эмодзи и символы — обычный Юникод (`public/emoji.js`); в песочнице Ozon показываются, поведение на модерации не проверено.
- Кнопки «Написать продавцу» в rich нет: ссылка на чат (`/my/chat?id=…`) — номер переписки конкретного покупателя, у других не работает (решение Марка 27.11.2026). Кнопка-ссылка в текстовом блоке — только на страницы ozon.ru.
- Картинка — прямая ссылка на `.jpg`/`.jpeg`/`.png`. Ссылки — только на ozon.ru.
- Плитки (проверено в песочнице Ozon 28.11.2026, схема v0.3 не ограничивает количество): `tileL` — по 3 в ряд, неполный ряд прижат влево; `tileXL` — по 2 в ряд, крупные; на телефоне — по одной. Блок «Плитки» раскладывается на несколько виджетов (`tileRows`, раскладка «Авто»: 1 → во всю ширину (`billboard` со ссылкой, при импорте снова плитка), 2 → 2 по половине, 4 → 2+2, 5 → 3+2 крупные, 6 → 3+3), при импорте склеивается обратно. Ровно по центру 2 плитки того же размера под тремя Ozon поставить не даёт.
- Таблица `raTable`: на телефоне столбец не уже 120 px, 3+ столбца листаются вбок. Картинки — только в шапке (`head[].img`, Ozon показывает 96×96), в строках нельзя. `hideHead` — таблица без шапки. Ссылки в ячейках — `{items:[…]}`.
- Ссылка внутри любого текста в редакторе пишется `[подпись](https://www.ozon.ru/…)` (кнопка «🔗 Ссылка»); не-ozon ссылки уходят простым текстом (`lineItems`, `readRich` в `rich.js`).
- Цвет в rich: Ozon красит только эмодзи (текст — 4 цвета, фон — голубой/серый/белый). Поэтому у «Профиля вкуса» и «Таблицы» есть вид (`look`): `table` — таблица (у вкуса — цветные шкалы 🟤⚪ и значки свойств 💪🍂🍯⚡, `iconFor`), `card` (только вкус) — `raTextBlock` на цветном фоне крупным текстом, `image` — цветная картинка, которую рисует `public/picture.js` (canvas, палитры `PALETTES`: Шу, ГАБА, зелёный, Ozon; ПК 1416 px, телефон 640 px); её скачивают, грузят в конструктор Ozon, ссылку вставляют в `pic`, в JSON уходит `roll` с alt-текстом (`pictureAlt`).
- «Инфографика вкуса» (`chart`) — 6 видов схем (`CHART_KINDS`: полоски, радар, шкала «от — до», колесо ароматов, карта вкуса, ноты вкуса). Значения вводятся в редакторе, картинку рисует `chartPicture` в `public/picture.js` (ПК 1416 px, телефон 640 px), в JSON уходит `roll` с картинкой из `pic` и описанием `chartAlt`. Обратно из JSON не восстанавливается — данные хранятся в шаблоне библиотеки. Цвета: 10 палитр по 12 цветов (`PALETTES`), свои фон/карточка/текст (`b.own`, `paletteOf`) и свой цвет у любого свойства/ноты/точки (`item.color`, `colorOf`). Марк делает инфографику для одного чая: при одном чае у каждого свойства (полоски, шкалы, точки радара) свой цвет, при нескольких — у каждого чая.
- «Профиль вкуса» (`taste`) — это `raTable` со шкалами ●●●○○ (★/■); при импорте таблица, где все ячейки кроме первого столбца — шкалы, снова становится профилем вкуса.
- «Карточки со значком» (`cards`) — `tileSecondary`: серые карточки, значок 50 px (на телефоне 40), на ПК по 4, на телефоне по 2. Плитки по 4 — `tileM` (раскладка «4»).
- Проверено в песочнице 28.11.2026: `isParandja` ничего не затемняет и текст всегда идёт под картинкой — «текста на фото» средствами JSON нет; `position` (половина/треть/четверть) в шахматке и списке на размер не влияет. Текстовый блок: `padding` type1 — без полей, type2 — с полями; `gapSize` s/m.
- Библиотека шаблонов — окно «📚 Библиотека» (`openLibrary` в `app.js`), шаблоны в `data/templates` на сервере, предпросмотр, копия, переименование, удаление. Блоки слева перетаскиваются мышкой.
- Длину текста Ozon не ограничивает (в схеме нет maxLength) — прежнее ограничение 260 знаков в шахматке убрано по просьбе Марка 28.11.2026, редактор только показывает число знаков.
- В шахматке 2–6 блоков. Карусели, анимации, GIF и HTML Ozon не поддерживает.
- Картинку для телефона, если её нет, берём из ПК (`resolveImage` в `public/rich.js`), и наоборот.
