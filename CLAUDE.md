# Редактор rich-контента Ozon — инструкция для работы с кодом

Инструмент раздела «Менеджмент» сайта tea-master-team.ru (магазин «Чайный Мастер» на Ozon). Владелец — Марк, не программист: общение и комментарии в коде на русском, объяснять простыми словами.

## Стек и правила

- Node.js 22, **без сторонних библиотек** (как «Воронка продаж WB»). Не добавлять npm-зависимости без решения Марка.
- Интерфейс — обычные ES-модули в `public/`, без сборки.
- Вход — только по ссылке из «Менеджмента» (`#t=ТОКЕН`, 60 минут), своего пароля нет (решение Марка). Токен проверяется запросом `AUTH_SQL` к базе сайта через `psql`.
- `.env` и `data/` в git не попадают.
- Перед коммитом: `npm test`.

## Формат Ozon

- JSON rich-контента версии 0.3. Виджеты и поля скопированы с живых карточек Ozon (ноябрь 2026): `raShowcase` (`billboard`, `chess`, `tileL`, `roll`), `raTextBlock`, `list` (`bullet`, `image`).
- Картинка — прямая ссылка на `.jpg`/`.jpeg`/`.png`. Ссылки — только на ozon.ru.
- В шахматке 2–6 блоков. Карусели, анимации, GIF и HTML Ozon не поддерживает.
- Картинку для телефона, если её нет, берём из ПК (`resolveImage` в `public/rich.js`), и наоборот.
