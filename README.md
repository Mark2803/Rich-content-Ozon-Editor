# Редактор rich-контента Ozon

Инструмент раздела «Менеджмент» сайта [tea-master-team.ru](https://tea-master-team.ru) для магазина «Чайный Мастер» на Ozon.
Собирает rich-контент карточки из блоков, показывает, как он будет выглядеть на компьютере и на телефоне, и выдаёт готовый JSON для вставки в Ozon.

## Что умеет

- **Блоки:** обложка, шахматка, плитки со ссылками на товары, картинки во всю ширину, заголовок и текст (4 варианта фона), вопросы и ответы, витрина магазина. Это все блоки, которые встречались в живых карточках Ozon при проверке в ноябре 2026.
- **Один набор блоков на два вида.** Компьютер и телефон — это одни и те же блоки, поэтому правка в одном виде сразу видна в другом. Если у картинки нет отдельной версии для телефона, подставляется картинка для ПК, и наоборот. Размер картинки редактор узнаёт сам, когда она загрузится.
- **Правка прямо в предпросмотре:** заголовки и тексты можно менять, нажав на них в карточке.
- **Ссылки на товары по SKU:** в плитках, витрине и картинках достаточно вписать SKU — адрес `https://www.ozon.ru/product/SKU/` подставится сам. Ссылки на другие сайты Ozon запрещает, редактор их не пропускает.
- **Проверка:** нет картинки, адрес картинки не `.jpg`/`.png`, шахматка не 2–6 блоков, текст длиннее 260 знаков, плитка без SKU.
- **Импорт:** вставьте JSON из любой карточки Ozon, и он откроется в редакторе для правки.
- **Шаблоны:** готовые «Смола шу пуэра» и «Смола ГАБА»; свои шаблоны сохраняются на сервере, и их видят все, у кого есть доступ к «Менеджменту». Перед перезаписью сервер хранит 10 прежних версий каждого шаблона.
- **Отмена** последних 60 действий (кнопка «Отменить» или Ctrl+Z).

## Как пользоваться

1. Админка сайта → «Менеджмент» → карточка «Редактор rich-контента Ozon». Ссылка действует 60 минут.
2. «Открыть шаблон…» → «Смола шу пуэра» или свой.
3. Слева выбрать блок, справа поменять текст, SKU и ссылки на картинки. Тексты можно править и прямо в карточке.
4. Картинки: загрузить инфографику в конструктор rich-контента в кабинете Ozon, скопировать её ссылку (`ozone.ru/…jpg`) и вставить в поле «Картинка для ПК». Поле «для телефона» заполнять, только если для телефона нарисован отдельный вариант.
5. Справа внизу — «Проверка». Когда замечаний нет, нажать «Получить JSON» → «Скопировать».
6. В Ozon: товар → «Редактировать» → «Медиа» → «Rich-контент JSON» → вставить.

## Выкладка на сервер

Делается под `root` в свежем SSH-терминале (команда входа — в проекте claude.ai, документ «Сервер — подключение»). Схема та же, что у «Воронки продаж WB».

```
cd /home/ivanc1539
runuser -u ivanc1539 -- git clone https://github.com/Mark2803/Rich-content-Ozon-Editor.git rich-content-ozon-editor
cd rich-content-ozon-editor
runuser -u ivanc1539 -- cp .env.example .env
nano .env
```

В `.env` заполнить:
- `SESSION_SECRET` — вывод команды `openssl rand -hex 32`;
- `DATABASE_URL` — та же строка, что в `/home/ivanc1539/tea-market-v2/backend/.env`;
- `AUTH_SQL` — уже верный в примере (тот же запрос, что у воронки WB).

Проверка и запуск службы:
```
runuser -u ivanc1539 -- npm test
cp deploy/rich-editor.service /etc/systemd/system/rich-editor.service
systemctl daemon-reload && systemctl enable --now rich-editor
sleep 2 && systemctl is-active rich-editor && curl -s http://127.0.0.1:3410/api/health
```

nginx: `cp deploy/nginx.ssl.conf_rich-editor /home/ivanc1539/conf/web/tea-master-team.ru/`, затем `nginx -t && systemctl reload nginx`.

Карточка в «Менеджменте»: в коде сайта (репозиторий TeaMarketV2) добавить карточку по образцу «Воронки продаж WB», которая ведёт на `/management/rich-editor/#t=ТОКЕН`. Токен выдаётся так же, как для воронки.

Обновление: `cd /home/ivanc1539/rich-content-ozon-editor && runuser -u ivanc1539 -- git pull && systemctl restart rich-editor`.
Журнал: `journalctl -u rich-editor -n 100`.

## Проверка на своём компьютере

Нужен Node.js 22. Библиотеки не нужны.

```
npm test        # проверка перевода в JSON Ozon и обратно
npm run dev     # http://127.0.0.1:3410/ без входа, только для проверки
```

## Устройство

- `public/rich.js` — блоки, перевод в JSON Ozon (версия 0.3) и обратно, подстановка картинок ПК ↔ телефон, проверка.
- `public/presets.js` — готовые шаблоны магазина.
- `public/app.js`, `index.html`, `style.css` — интерфейс.
- `server.js` — сервер без сторонних библиотек: страница, вход по токену из «Менеджмента» (cookie на 60 минут), общие шаблоны в `data/`.
- `tests/` — автотесты (`npm test`).
